# Placas & Sociedade — Durkheim

Protótipo educacional em HTML/CSS/JavaScript puro para GitHub Pages.

## Como usar
1. Extraia o ZIP.
2. Crie um repositório no GitHub.
3. Envie `index.html`, `style.css`, `game.js` e a pasta `assets`.
4. Em **Settings → Pages**, escolha a branch principal e a pasta `/root`.
5. Abra o endereço do GitHub Pages.

## O que existe no protótipo
- Introdução conceitual a Émile Durkheim.
- 10 flashcards de sinalização japonesa.
- Animação 3D de virar o card.
- Teste de memória com 5 perguntas.
- Minijogo 2D de direção em canvas.
- Objetivo aeroporto → farmácia.
- Controles WASD/setas e botões touch.
- Tela final relacionando aprendizagem de regras e ação.

## Observação acadêmica
O texto evita afirmar que cada placa, isoladamente, constitui um “fato social”. O jogo usa o sistema coletivo de regras e sinalizações como exemplo didático para discutir exterioridade, coerção e compartilhamento de normas.
